# Digimon GraphQL App

A React application that fetches and displays Digimon information using GraphQL and Apollo Client. Browse through various Digimon, view their stats, types, descriptions, and evolution chains.

## Features

- Display Digimon with images, levels, and types
- View Digimon descriptions 
- Show evolution chains (digivolutions)
- Built with React and Apollo Client
- GraphQL API integration

## Technologies Used

- React
- Apollo Client
- GraphQL
- Vite

## API

This project uses the Digimon GraphQL API: `https://digimon-graphql.vercel.app/`
